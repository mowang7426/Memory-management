# Memory-management

RootHide 越狱插件项目，目标是在 iOS 15.0–17.0 上为用户提供按 App 配置的后台自启动管理。

> 当前版本：1.0.0 测试版。用户可选择第三方 App；若目标 App 冷启动后 5 秒内始终没有进入前台、仍处于后台，插件会记录事件并结束该次后台进程。用户主动打开正常放行。该机制会影响被选 App 的后台刷新、推送处理、定位、音频或 VoIP，不保证固定释放多少内存。

## 安全目标

- 仅处理用户明确选择的第三方 App；系统关键进程默认排除。
- 用户主动启动必须放行。
- 无法可靠识别启动来源时放行，避免误伤推送、定位、音频、VoIP、分享和登录回跳。
- 不通过禁用系统 launchd job、修改 Jetsam 阈值或终止 SpringBoard 来实现。
- 提供全局暂停/恢复、逐 App 白名单和可审计事件记录。

## 开发阶段

1. **技术验证**：分别研究 iOS 15、16、17.0 + RootHide 下可观测的启动路径，验证是否能区分用户启动与后台触发。
2. **设置与偏好**：应用列表、逐 App 策略、全局暂停、日志与恢复默认。
3. **有限拦截**：只在启动来源可确认且属于用户启用策略时拦截；其余放行。
4. **构建验证**：分别构建 arm64、arm64e 包，检查 deb 内容、注入范围、设置页和偏好读写。
5. **真机回归**：通知、后台刷新、定位、VoIP、分享、登录回跳及设备重启场景。

## 内存预期

减少后台唤醒或驻留不等于保证空闲内存。iOS 会主动使用空闲内存做缓存；插件不承诺固定保留 1000 MB。

## 当前进度

iOS 17.0 首个直接功能版已实现：设置页列出第三方 App 并保存勾选项；运行时仅在选中 App 内工作。App 若曾进入前台则本次进程永久放行；只有冷启动后始终未进入前台且 5 秒后仍处于后台时才结束进程。系统 `com.apple.*` App 默认排除，全局开关默认关闭。仍需 arm64/arm64e 构建和 iOS 17.0 真机验证，尤其是 RootHide 下跨进程偏好读取、App 列表与推送场景。
